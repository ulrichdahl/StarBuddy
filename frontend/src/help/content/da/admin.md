# Admin

Siden Admin er til officerer, managere og admins i din hoved-org. Andre kan ikke se den.

![Admin](screens/web-admin.jpg)

## Ryd lager for hele org'en

Fjerner materialestakke, og genstande hvis du vælger det, fra medlemmerne af din org. Ingen uden for org'en bliver berørt.

- **Alt (game wipe):** efter et server-wipe. Fjern flueben ved de materialekategorier, der overlevede patchen. Sæt kun flueben ved genstande, hvis patchen tog dem. Blueprints, placeringer og raffinaderiordrer bliver liggende.
- **Efter kategori** eller **Efter ressourcetype:** for én slags materiale.
- **Medlem** og **lokation** afgrænser yderligere.
- `Ryd også org-medlemmernes private lagre` tager de private stakke med. Ellers forsvinder kun org-synlige stakke.

Skriv `CLEAR` for at bekræfte. Det kan ikke fortrydes.

Medlemmer, der kun vil rydde deres eget lager, bruger `Ryd mit lager…` i deres [profil](profile).
