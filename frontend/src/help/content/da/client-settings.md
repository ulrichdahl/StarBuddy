# Klientens indstillinger

Åbn `Indstillinger` i klientens menu.

| Fane | Hvad der er |
| --- | --- |
| Generelt | Åbn StarBuddy som overlay eller vindue, server og parring, deling af spilstatus, og sproget |
| Genvejstaster | Alle genvejstaster, og `Nulstil alle genveje`. Se [Vinduer over spillet](client-overlays) |
| Spilinstallation | Hvor spillet ligger, `Scan loghistorik` og logovervågningen. Se [Installér og par](client-setup) |
| Skærmaflæsning | Skærmaflæsning til eller fra, raffinaderiordre-området og deling af aflæsninger til træning. Se [Skærmaflæsning](client-screen-reading) |
| Opdateringer | Din version, `Søg efter opdateringer`, og hvad der er ændret |
| Fejlsøgning | Den sidste genvejstast StarBuddy modtog, KDE-vinduesreglen på Linux, og systemoplysninger, du kan indsætte, når du beder om hjælp |
| Kreditering og licenser | StarBuddys licens, og hvad den er bygget på |

![Indstillinger › Skærmaflæsning](screens/client-settings-reading.jpg)

## Opdateringer

Klienten søger selv efter en ny version. Når der er en, så tryk `Installér og genstart`. **Hvad er ændret** viser ændringerne.

## Når du beder om hjælp

Åbn `Fejlsøgning`, tryk `Kopiér` ved systemoplysningerne og indsæt dem sammen med dit spørgsmål på fællesskabets Discord, eller meld fejlen på GitHub.
