# Admin

The Admin page is for the officers, managers and admins of your main org. Everyone else does not see it.

![Admin](screens/web-admin.jpg)

## Bulk-clear inventory

Removes material stacks, and items if you choose, from the members of your org. Nobody outside the org is affected.

- **Everything (game wipe):** after a server wipe. Untick the material categories that survived the patch. Tick items only if the patch took them. Blueprints, locations and refinery orders are kept.
- **By category** or **By resource type:** for one kind of material.
- **Member** and **location** narrow it further.
- `Also clear the org members' private stock` includes private stacks. Otherwise only org-visible stacks go.

Type `CLEAR` to confirm. It cannot be undone.

Members who only want to clear their own stock use `Clear my stock…` in their [profile](profile).
