# Client settings

Open `Settings` in the client's menu.

| Tab | What is there |
| --- | --- |
| General | Open StarBuddy as overlay or window, the server and signing in, `Run setup again`, game status sharing, and the language |
| Hotkeys | Every hotkey, and `Reset all bindings`. See [Windows over the game](client-overlays) |
| Game install | Where the game is, `Scan log history` and the log watcher. See [Install and pair](client-setup) |
| Screen reading | Screen reading on or off, the refinery order area, and sharing reads for training. See [Screen reading](client-screen-reading) |
| Updates | Your version, `Check for updates`, and what changed |
| Diagnostics | The last hotkey StarBuddy received, the KDE window rule on Linux, and a system report to paste when you ask for help |
| Credits and licenses | StarBuddy's license and what it is built on |

![Settings › Screen reading](screens/client-settings-reading.jpg)

## Updates

The client checks for a new version by itself. When one is out, press `Install and restart`. **What's new** lists the changes.

## Asking for help

Open `Diagnostics`, press `Copy` on the system report and paste it with your question in the community's Discord, or report the problem on GitHub.
