# Import

Import adds many material stacks at once from a CSV file, for example from a spreadsheet you kept before StarBuddy.

![Import](screens/web-import.jpg)

1. Press `Download CSV template` to get the columns StarBuddy reads.
2. Fill it in, one stack per row, and save it as CSV.
3. Press `Choose CSV file`. StarBuddy shows a preview: valid rows, and rows with errors with the reason.
4. Press `Commit import`. Rows with errors are skipped.

Rows are matched to members by their Star Citizen handle, so set yours in your [profile](profile) first.
