# Windows over the game

The client can sit over the game, so you do not have to Alt+Tab out of Star Citizen.

## StarBuddy itself

`Insert` shows and hides StarBuddy. In `Settings` › `General`, **Open StarBuddy as** chooses:

- **Overlay:** over the game without a frame. The hotkey shows and hides it, and it stays where you put it.
- **Window:** a normal desktop window you switch to with Alt+Tab.

While the game is not running, StarBuddy always opens as a window.

## The small windows

![Overlay windows](screens/client-overlays.jpg)

| Window | Shows | Default key |
| --- | --- | --- |
| Status | The Star Citizen services: green when all is fine, amber with a countdown to maintenance | `F6` |
| Scan | What the rock you scanned holds | opens with `F7` |
| Refinery order | The order read at the terminal | opens with `F8` |
| Blueprint pools | The pools you track and what is left in each | none |
| Gathering | Your shopping list | none |
| Refinery orders | Your open orders, ready ones first and framed green. Each fills up as it refines, with the station, time left, ores and total yield | none |
| Your points | Your points this month and your org's rank | none |
| Location (experimental) | Direction, distance and arrival time to a beacon. See [Location beacons](client-beacons) | none |

Open and close them from **Windows over the game** on Home, or give each one a key in `Settings` › `Hotkeys`. One more key can hide every open window and show them again.

Each window has controls at the top: placement (floating, or docked to an edge), opacity, collapse and close.

## Hotkeys

![Settings › Hotkeys](screens/client-settings-hotkeys.jpg)

| Key | Does |
| --- | --- |
| `Insert` | Show or hide StarBuddy |
| `F6` | Show or hide the status window |
| `F7` | Start or stop reading mining scans |
| `F8` | Read the refinery order on screen |
| `F9` | Send a screenshot for scan training (testers only) |
| `F10` | Switch screen reading on or off |

Change a key in `Settings` › `Hotkeys`: click it and hold the new combination. `Reset all bindings` puts every key back. `Settings` › `Diagnostics` says which key last reached StarBuddy, which helps when a key seems to do nothing. See [Troubleshooting](troubleshooting).
