StarBuddy · overlay windows

Window modes — icon set

Every overlay window carries the same four buttons at the right of its title bar, left to right: size (toggles Full / Minimal), placement (shows the current mode — floating or docked to one edge — and opens a five-zone picker), opacity (a slider, remembered per window), close. One family, 24-px grid, 1.5-px strokes, the Launcher's cut corner, cyan when active. The placement glyphs are a tiny screen with the window's footprint filled in, so each icon shows exactly where the window sits; the size glyphs are the window itself with more or less inside.

The set

Nine icons. Filled shapes mean "where on the screen", line-only shapes mean "the window itself"; opacity is the window split on the diagonal, one half glass; close is the plain cross of the same stroke. Shown at 36, 18 and 14 px — 14 px is what a minimal window's title bar uses.

Placement familyA 20×16 screen outline with the docked area filled. Left/right fill the full height — the window slides up and down along that edge, and the faint dotted tick in the free half hints at the drag axis. Top/bottom fill a centred 12-wide strip: shorter and centred, because those two cannot be dragged.
FloatingThe window frame in front, a second dashed frame offset behind it: lifted off the surface, free to move. It is the only placement glyph with the cut corner, because it is the only one that is a "card".
Size familyThe window frame with its title-bar rule. Full has three body lines of decreasing length; Minimal is shorter and holds one filled block — the "first box" that survives the collapse.
ColourIdle steel #7fa0b8, hover white, active cyan #3CC9F0 on a 12 % cyan wash with a cyan hairline. Only the placement button is ever "active" — it always shows the current mode. Disabled (the size button while docked top/bottom) drops to 30 % opacity.
Opacity is per windowThe scan window, the mining window and the status alert each keep their own value (e.g. scan 85 %, alert 100 %, mining 70 %). The slider runs 25–100 % — the floor keeps a window from vanishing — previews live while dragging, and the mouse wheel over the button nudges it in 5 % steps. Applies to the whole window; the title bar glyphs stay at full strength on hover so the controls remain findable.
Size button shows the targetLike a window's minimise/maximise glyphs: on a Full window it shows Minimal ("collapse"), on a Minimal window it shows Full ("expand"). One button, one click, no pair.

Floating · full (left), minimal (right) with the placement picker open; opacity slider open on the alert
  • Placement picker: the five zones are laid out like the screen (floating in the middle); the current mode is cyan. Click a zone or press Esc; the popover also closes when the pointer leaves it.
  • Opacity popover: one slider with the window's name under it so it is clear which window's value you are changing; a thin tick marks the 25 % floor. Closes on pointer-leave like the placement picker.
  • Minimal keeps the most useful box: for the scan window that is the signature row; for the alert it is the countdown and the stow call. Each window declares which box is first.
  • Double-click the title bar toggles Full/Minimal as a shortcut; the icons stay so the state is visible without hovering.
  • The cluster fades to 45 % when the cursor is away from the window and returns on hover, so the glyphs do not compete with the game.

In place — docked (design 2)

Docked left: the window hugs the edge, keeps its cut corner on the free side, and slides along the edge (the drag-range marker). Docked top: a centred strip with no grip, no drag, and the size button disabled — a strip is always minimal by construction.

Docked top (strip, size disabled) and docked left (cluster moves to the foot when the title bar is too narrow)
  • Narrow windows move the cluster to the foot instead of shrinking the title. Same buttons, same order.
  • Switching placement keeps the size state (a minimal floating window docks left as minimal), except top/bottom, which force the strip and restore the previous state when you leave them.
  • Edge snap: dragging a floating window within 24 px of an edge previews that dock (the edge glows cyan); releasing docks it. Dragging a docked window away from its edge returns it to floating.
